# Rivea Motos Elétricas

Site institucional estático (HTML/CSS/JS, sem build). Os arquivos publicados ficam em `dist/`.

## Vercel

Importar a raiz do repositório com framework **Other**. O `vercel.json` define a saída `dist`, sem build nem instalação.

## Dados usados (perfil do WhatsApp Business e mensagem de boas-vindas, 23/11/2026)

| Campo | Valor |
|---|---|
| Nome | Rivea Motos Elétricas |
| Atividade | Venda e locação de motos elétricas ("Viagem e transporte · Serviço automotivo") |
| Local | Canasvieiras, Florianópolis - SC (sem número de rua no perfil) |
| WhatsApp | (48) 8840-6435 (`wa.me/554888406435`, número do perfil sem alteração) |
| Horário | "Aberta 24 horas" no perfil |
| Locação | 30 minutos ou 1 hora; dados pedidos: nome, documento com foto, hospedagem, contato adicional |
| Slogan | "Liberdade para viver o melhor do litoral" |

## Confirmar com o cliente

- Endereço ou ponto de retirada exato (o mapa mostra o bairro Canasvieiras como região).
- Preços, modelos à venda, exigência de idade/habilitação e regras de uso (capacete, área permitida).
- Logo em boa resolução e fotos reais das motos (as fotos atuais são ilustrativas).
- Se o atendimento é mesmo 24 horas.

## Imagens

Fotos ilustrativas do Unsplash, com créditos em `dist/assets/credits.md` e `dist/assets/credits.html`.

## Direção visual (Taste)

*Photographs at uneven sizes*: fotos do litoral em tamanhos e alturas diferentes, como cópias numa parede,
com texto curto entre elas. Tipografia Young Serif + Source Serif 4; paleta de areia e laranja do pôr do sol
da logo. Item interativo: montador de reserva (tipo, tempo, quando, quantidade) que abre o WhatsApp.
Hero no padrão obrigatório Aroe.
